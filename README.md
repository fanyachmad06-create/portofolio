## 🚀 Menjalankan Proyek Secara Lokal (*Getting Started*)

Pastikan Anda telah menginstal **Node.js** (versi 18+ disarankan):

```bash
# 1. Clone repositori ini
git clone https://github.com/fanyachmad06-create/portfolio.git
cd portfolio

# 2. Instal dependencies
npm install

# 3. Jalankan server pengembangan lokal (HMR)
npm run dev

# 4. Buka browser pada URL yang muncul:
# http://localhost:5173/
```

### Script Lainnya:
```bash
npm run build      # Kompilasi produksi ke folder /dist
npm run preview    # Menjalankan preview lokal hasil build produksi
```

## ☁️ Deployment ke Vercel

Proyek ini telah dilengkapi file konfigurasi [`vercel.json`](./vercel.json) untuk Single Page Application (SPA) Vite.

1. Buka [Vercel](https://vercel.com) dan login dengan akun GitHub Anda.
2. Klik **"Add New..."** $\rightarrow$ **"Project"**.
3. Import repositori `portfolio` ini.
4. Klik **"Deploy"**. Vercel akan otomatis menjalankan `npm run build` dan menyajikan folder `dist` secara instan.
